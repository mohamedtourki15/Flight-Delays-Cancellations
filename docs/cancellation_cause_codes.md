# Cancellation Cause Codes

The Kaggle dataset has a `CANCELLATION_REASON` column with one letter per cancelled flight. In the dashboards these letters are renamed to full names.

| Code | Name in the dashboards |
|------|------------------------|
| A | Airline/Carrier |
| B | Weather |
| C | National Air System |
| D | Security |

Source of the code meanings: US Bureau of Transportation Statistics, [reporting directive](https://www.bts.gov/topics/airlines-and-airports/number-21-technical-directive-time-reporting-effective-jan-1-2012) (A carrier, B weather, C national aviation system, D security).
